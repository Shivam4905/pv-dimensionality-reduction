# Third-party components

The project's own code (`main.m` and the accompanying functions) is released
under the MIT license — see [`LICENSE`](LICENSE).

It bundles one external component, which keeps its **own, more restrictive
license** and is **not** covered by MIT:

## Matlab Toolbox for Dimensionality Reduction (`drtoolbox/`)

Version 0.8b, by **Laurens van der Maaten** (Delft University of Technology),
redistributed unmodified so the project runs out of the box.

Each toolbox file states its terms:

> "You are free to use, change, or redistribute this code in any way you want
> for non-commercial purposes. However, it is appreciated if you maintain the
> name of the original author."

In short: **non-commercial use only, with attribution.** Any commercial use must
refer to the toolbox's original terms and its author.

References:

- L. van der Maaten, *Matlab Toolbox for Dimensionality Reduction*, Delft
  University of Technology, 2007–2014. <https://lvdmaaten.github.io/drtoolbox/>
- L. van der Maaten, E. O. Postma, J. van den Herik, *Dimensionality Reduction:
  A Comparative Review*, 2008.
